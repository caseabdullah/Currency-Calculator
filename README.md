# 💱 Currency Converter

A responsive and interactive Currency Converter website built with JavaScript, allowing users to convert currencies using exchange rates retrieved from an external API.

## 📌 About the Project

This project demonstrates how to integrate third-party APIs into a frontend application to retrieve exchange-rate data and perform currency conversions dynamically.

Instead of relying on predefined exchange rates, the application communicates with an external API to fetch currency information and calculate conversions.

## 🛠️ Technologies Used

- **HTML5** – Structuring the application.
- **CSS3** – Styling and responsive user interface.
- **JavaScript (ES6+)** – Application logic and dynamic functionality.
- **Fetch API** – Making HTTP requests to external APIs.
- **Exchange Rate API** – Retrieving currency exchange-rate data.

## ⚙️ Key Features

- Convert between different currencies.
- Select base and target currencies.
- Enter custom amounts for conversion.
- Fetch exchange rates from an external API.
- Display dynamically calculated conversion results.
- Interactive and user-friendly interface.

## 🧠 Concepts Implemented

- **API Integration:** Connecting the application with an external exchange-rate API.
- **Fetch API:** Sending HTTP requests to retrieve exchange-rate information.
- **Asynchronous JavaScript:** Using `async/await` to handle API requests.
- **Promises:** Managing asynchronous operations and API responses.
- **JSON Parsing:** Extracting exchange-rate information from API responses.
- **DOM Manipulation:** Dynamically updating conversion results.
- **Event Handling:** Responding to user interactions and currency selections.
- **Error Handling:** Managing failed API requests and unexpected responses.
